# ChatAIO 脚本

在 **monorepo 根**执行。本目录 `package.json` 同名 script 会 `--cwd` 回根，参数相同。追加参数：`yarn <script> -- ...`

| 命令 | 参数及说明 |
|------|------------|
| `yarn start:webpack` | script 已写死 `ChatAIO 4444`，日常不用再传。<br><br>**手写 tsx 时的位置 token**（`engine/toolkit/entrance.ts`，按正则认领、顺序无关）<br>`ChatAIO` — 子工程，对应 `projects/ChatAIO`<br>`4444` — DevServer 起始端口；被占则 portfinder 顺延，结果编进 `__DEV_PORT__`<br>`production` / `development` — webpack mode（本入口默认 development）<br>`mock` / `experimental` — DefinePlugin 开关（常用入口不传）<br><br>先开这一条，再 `start:electron`。产物 `projects/ChatAIO/dist/`，renderer 走 HTTPS WDS。 |
| `yarn start:electron` | 无 CLI。加载本工程 `dist/`；main 带 `--inspect=9229`。<br><br>**环境变量**<br>`CHATAIO_REMOTE_DEBUG=1` — Chromium CDP `9222`（默认关）<br>`CHATAIO_CATALOG_REMOTE_JSON` + `CHATAIO_CATALOG_REMOTE_SIG` — 目录检查改读本地已签名文件<br>不要设 `CHATAIO_E2E=1`（那是 Playwright 启动时写的）。 |
| `yarn build:webpack` | 已写死 `ChatAIO production`。产物 `dist/`（不是安装包）。E2E / 出包前要先跑；改 Main 或 Settings 后须重跑，E2E globalSetup 只在缺文件时构建。 |
| `yarn build:electron` | 默认打**当前宿主**平台，输出 `projects/ChatAIO/__Bin/`。yml：win=`nsis/x64`，mac=`dmg+zip / x64+arm64`，linux=`AppImage/x64`。<br><br>**wrapper 能从 yarn 扫到的短名单**<br>`--win` `-w` / `--mac` `-m` / `--linux` `-l` / `--arm64` / `--x64`<br><br>**其它 electron-builder CLI**（`--publish`、`--dir`、`--universal` 等）必须走：<br>`yarn tsx scripts/electron.build/index.ts ChatAIO -- --win --publish never`<br>以日志 `[ElectronBuild] electron-builder ...` 为准。<br><br>**环境变量（Windows 清 `__Bin`）**<br>`LOCKHUNTER_PATH` / `LOCKHUNTER_EXE` |
| `yarn build` | 无参数。`build:webpack` 然后 `build:electron`（当前宿主）。 |
| `yarn test` | 无参数 = 跑 script 里列出的全部 `.test.ts`（勿把 `tests/` 目录丢给 `tsx --test`，会去找 `index.json`）。<br><br>`yarn test -- <file>` 是**追加**文件，不会缩小集合。只跑一部分要用：<br>`yarn tsx --tsconfig projects/ChatAIO/tsconfig.json --test projects/ChatAIO/tests/<file>.test.ts`<br><br>`ai-list-reorder.test.ts` — 排序契约<br>`manage-ais-table-ux.test.ts` — 表展示序 / 筛选<br>`settings-dirty-scopes.test.ts` — 页脚 vs 表底 dirty<br>`menubar-cold-start-verdict.test.ts` — menubar 冷启动裁决<br>`ai-catalog-defaults.test.ts` / `merge` / `sign` / `update` — 供应商目录<br>`close-without-tray-process-lingers.test.ts` — 禁用托盘后点 X |
| `yarn test:e2e` | Playwright，config=`projects/ChatAIO/e2e/playwright.config.ts`，测仓库内 Electron。<br><br>**CLI（接在 `--` 后）**<br>`--headed` — 有窗（unpackaged 本来就有，几乎无差别）<br>`--debug` — Inspector<br>`--ui` — UI Mode<br>`projects/ChatAIO/e2e/tests/<file>.spec.ts` — 单文件<br><br>**环境变量**<br>`CHATAIO_E2E_WATCH=1` — 高亮 / 叠加 / 提窗 / 开 trace（不是 Playwright `--watch`）<br>`CHATAIO_E2E_SLOWMO_MS` — 每次点击前后停顿，WATCH 默认 600，否则 0<br>`CHATAIO_E2E_HOLD_MS` — 关窗前停住，WATCH 默认 2000，否则 0<br>`CHATAIO_E2E_DEBUG=1` — 打 Electron stdout/stderr<br>`CHATAIO_E2E_NO_COLOR=1` — 关 reporter 颜色<br>`CHATAIO_E2E_SKIP_BUILD=1` — `dist/` 缺失时不要自动 `build:webpack`，直接失败<br>`CI` — retries=2、forbidOnly<br><br>观测全量：`yarn cross-env CHATAIO_E2E_WATCH=1 yarn test:e2e`<br>用例与不变量见 [`docs/features/e2e-playwright.md`](./docs/features/e2e-playwright.md)。 |
| `yarn tsx --tsconfig projects/ChatAIO/tsconfig.json projects/ChatAIO/scripts/analyze-perf-logs.ts` | `--ci` — 超阈值 `exit 1`（avg main 30ms / 单次 100 / close 80 / close 动画 1000 / P1 异常 10）<br>`--latest` — 只分析最新一条非 `perf-fixture-*`<br>`--dir <path>` — 日志目录，默认 `projects/ChatAIO/performance-logs/`<br>报告写到该目录 `analysis-reports/`。 |
| `yarn tsx --tsconfig projects/ChatAIO/tsconfig.json projects/ChatAIO/scripts/analyze-menubar-cold-start.ts` | 可选路径：第一个非 `--` 的 argv 当 jsonl。<br>未传则依次找：`<cwd>/logs/menubar-cold-start.jsonl` → `projects/ChatAIO/logs/...` → 脚本旁 `../logs/...`。 |
| `yarn tsx --tsconfig projects/ChatAIO/tsconfig.json projects/ChatAIO/scripts/sign-ai-catalog.ts` | 无 CLI。签 `statics/ai-catalog/default-ais.json`。<br><br>**私钥**<br>`CHATAIO_CATALOG_ED25519_PRIVATE_KEY` — PEM 全文（`\\n` → 换行）<br>`CHATAIO_CATALOG_ED25519_PRIVATE_KEY_FILE` — 路径<br>默认 `~/.chataio/ai-catalog-ed25519.key`<br><br>JSON 必须 LF；禁止实例字段 `disabled` / `proxy_mode` / `preloadOnStartup` / `url_override`。 |
| `yarn tsx --tsconfig projects/ChatAIO/tsconfig.json projects/ChatAIO/scripts/publish-ai-catalog.ts` | 无 CLI。需已签名 + `gh` 已登录。内部 `gh release` 已写死 `--latest=false`，不要把 `ai-catalog` 标成 GitHub Latest。 |
| `yarn replace-app-icons` | `<PNG绝对路径>` — 必填，相对路径会退出<br>`--project ChatAIO` — 默认已是 ChatAIO<br>`--variant prod` \| `dev`<br>`--dry-run` / `--list-projects`<br>详见 [`scripts/replace-app-icons/AGENTS.md`](../../scripts/replace-app-icons/AGENTS.md)。不要手改 `.ico` / `.icns`。 |
| `bash projects/ChatAIO/scripts/generate-icons.sh` | 仅 macOS（`sips` / `iconutil` / `python3`+Pillow）。<br>`--no-clean` — 不删旧图标文件。跨平台换图用上一行。 |
| `yarn setup:git-symlinks` | `--restore` — 把已退化成普通文件的跟踪软链 `git checkout` 回来。<br>无退化则成功；有退化且未加 `--restore` 时只报告并失败。 |
| `.\node_modules\.bin\tsc.cmd -p projects\ChatAIO\tsconfig.json --noEmit` | 不是 npm script。Settings 另用 `-p projects\ChatAIO\src\Views\SettingsView\tsconfig.json`。<br>无关红线可加 `--typeRoots .\node_modules\@types --skipLibCheck`。 |
